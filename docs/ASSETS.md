## Replacing the hero video
Drop a compressed MP4 (H.264, no audio, ideally under 2 MB, 8 to 15 s seamless loop) at `public/assets/videos/hero-background.mp4` and a matching poster at `hero-poster.jpg`, then **record the source URL and license here**. Suggested sources: pexels.com/videos, pixabay.com/videos, coverr.co. Choose light, blue/neutral footage; the overlay in `.hero-overlay` keeps the text readable.

## Theme-specific visual treatment
The hero MP4 is shared between themes. Theme-specific CSS filters and overlays adapt its appearance; no duplicate video asset is required. The brand SVG mark is also theme-aware through CSS variables in `Brand.jsx` and `global.css`.


### Theme-aware SVG illustrations
The inline SVG illustrations in `src/components/visuals.jsx`, `src/components/ServiceArt.jsx`, and `src/components/GradientDefs.jsx` are original vector artwork. Their fills, points, lines, and gradients are driven by CSS variables in `src/styles/global.css`, allowing dark/light theme adaptation without duplicate image files.


### Inline SVG illustrations
The About page illustration is authored inline in `src/components/visuals.jsx` as original SVG artwork. It uses CSS theme variables and requires no external image download or third-party asset license.
